open source speech2insight

Audio to insight in five reproducible stages

An open-source pipeline that turns audio into transcripts, sentiment, topics and summaries, Dockerised and evaluated with BLEU and ROUGE.

Role
sole author · Timeline: 2025 · Team: 1
Stack
Whisper · HuggingFace · Streamlit · Docker · GitHub Actions
Code
open source on GitHub

01Problem

Recorded conversations hold sentiment, topics and decisions, but nobody listens to hours of audio. The aim was a pipeline that takes an audio file and returns a structured summary of what was said and how it landed.

02Constraints

  • Must run on anyone's machine, including the ffmpeg dependency Whisper needs.
  • Each stage should be swappable and testable on its own.
  • Summaries need a measurable quality bar, not just a good-looking demo.

03Architecture

04Key decisions

  • Five small stages instead of one model. Each stage has one job and can be replaced without touching the others.
  • Chunked summarisation with BLEU / ROUGE evaluation. Long transcripts are split to fit T5's input window, and quality is scored instead of eyeballed.
  • Docker with ffmpeg bundled and CI/CD to GHCR. The same image runs locally and in the pipeline, which removes the usual dependency setup.

05Data model · Output contract

insight.json
  transcript    full text from whisper
  sentiment     per segment (TextBlob + DistilRoBERTa)
  topics        LSA topic terms
  summary       T5, chunked, scored with BLEU / ROUGE
