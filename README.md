# Portfolio · utkarsh sawant

Personal site for **Utkarsh Sawant** — Data Engineer based in Germany.
Single-page portfolio with about, stack, projects, experience, and contact.

**Live:** https://utkarshsawant65.github.io/Portfolio-website/

## Stack

Static site, no build step.

- HTML5 / CSS3 / vanilla JavaScript
- Google Fonts (Inter, Space Grotesk, JetBrains Mono)
- Hosted on GitHub Pages, deployed from `main`

## Local dev

```bash
git clone https://github.com/utkarshsawant65/Portfolio-website.git
cd Portfolio-website
# any static server works, e.g.:
python -m http.server 8000
# then open http://localhost:8000
```

## Structure

```
.
├── index.html      # single page, all sections inline
├── css/styles.css  # design tokens + layout + animations
├── js/main.js      # canvas bg, cursor, scroll reveals, nav, filters
└── assets/         # images (resume PDF is git-ignored)
```
